# FEAT-006 · 多标签文件夹窗口

- **状态**：**已下线（v1.6.0 移除）**
- **存在版本**：v1.5.0 ~ v1.5.0（仅一个版本）
- **首次版本**：v1.5.0
- **下线原因**：用户要求必须在 **Windows 资源管理器**中打开，自建窗口不满足（见 REQ-004、Q-002）
- **关联需求**：REQ-004（已回退）
- **原代码位置**：`FolderTab`、`FolderTabsWindow`、`LauncherWindow.open_folders_in_tabs()`（均已删除）

> 本文档仅作历史存档。当前版本（v1.6.0 起）所有文件夹均由系统资源管理器打开。

## 它做什么

把一次启动涉及的多个文件夹放进**同一个窗口的不同标签页**，避免资源管理器窗口铺满任务栏。

## 触发方式

| 场景 | 结果 |
|---|---|
| 「🚀 一键启动」，列表中有 **≥2 个文件夹** | 打开（或复用）一个窗口，每个文件夹一个标签 |
| 「🚀 一键启动」，列表中有 **1 个文件夹** | 仍由系统资源管理器打开 |
| 双击列表中的文件夹 | 系统资源管理器打开该目录 |
| 已打开文件夹窗口，再次一键启动 | 在现有窗口中追加标签，不新建窗口 |

## 窗口结构

```
┌ 文件夹 · 3 个 ───────────────────────────────┐
│ [项目A] [项目B] [项目C]                    × │  ← 标签可关闭、可拖动排序
├──────────────────────────────────────────────┤
│ ←  ↑  [ E:\...\项目A            ] [资源管理器] │
├──────────────────────────────────────────────┤
│ 名称                │ 大小 │ 类型 │ 修改日期  │
│ 📁 子目录           │      │ ...  │ ...       │
│ 📄 说明.txt         │ 5 KB │ ...  │ ...       │
├──────────────────────────────────────────────┤
│ [全部用资源管理器打开]              [关闭]    │
└──────────────────────────────────────────────┘
```

## 标签内操作

| 操作 | 行为 |
|---|---|
| 双击目录 | 在当前标签内进入（不新开窗口） |
| 双击文件 | 交给系统默认程序打开 |
| `←` | 返回上一个访问过的目录 |
| `↑` | 进入上级目录（到盘符根时禁用） |
| 地址栏输入 + 回车 | 跳转到该目录，非法路径会提示并还原 |
| 「资源管理器」 | 用系统资源管理器打开当前目录 |
| 关闭最后一个标签 | 窗口随之关闭 |

## 实现要点

- 每个标签持有独立的 `QFileSystemModel`，并在每次导航时 `setRootPath()`
  —— 这是模型真正扫描目录的前提，共用模型会导致列表为空。
- 标签标题取目录名，tooltip 显示完整路径；重复目录不会重复添加。
- 窗口通过 `folders_requested` 信号由后台线程请求、主线程创建，避免跨线程操作 GUI。
- 窗口关闭采用 `WA_DeleteOnClose`，引用由 `destroyed` 信号清空，可再次创建。

## 与系统资源管理器的差异

这是一个**轻量目录浏览窗口**，不是资源管理器替代品：

- 不支持复制/粘贴、拖拽移动文件、右键菜单、预览窗格、地址栏历史下拉；
- 文件操作请点「资源管理器」转回系统窗口完成。

## 性能

每个标签一个模型，意味着每个标签一个文件监视器线程。常见 3–10 个文件夹无压力；
若预设包含几十个文件夹，建议拆分为多个预设，或只保留常用目录。
