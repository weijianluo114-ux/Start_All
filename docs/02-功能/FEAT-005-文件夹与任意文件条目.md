# FEAT-005 · 文件夹与任意文件条目

- **状态**：可用
- **首次版本**：v1.4.0
- **关联需求**：REQ-003
- **代码位置**：`normalize_input_path()` / `entry_kind()` / `entry_label()` / `entry_tooltip()`；
  `LauncherWindow.add_folder_dialog()` / `add_path_manually()` / `dropEvent()`

## 它做什么

列表不再只容纳程序：文件夹、文档、图片等任意路径都能编进预设，一键启动时按系统默认方式打开。

## 入口

| 入口 | 行为 |
|---|---|
| 📁 添加文件夹 | 目录选择对话框，起始位置为上次使用的文件夹 |
| 📂 添加程序 | 多选文件对话框，过滤器可选「程序」或「所有文件」 |
| ✏ 输入路径 | 手动输入 / 粘贴路径，支持环境变量与引号 |
| 拖拽到窗口 | 文件与文件夹都可拖入，支持一次拖多个 |

## 显示规则

| 类型 | 列表文字 | tooltip 首行 |
|---|---|---|
| 文件夹 | `📁 目录名` | `文件夹` |
| 普通文件 | 文件名 | `文件` |
| 失效路径 | `⚠ 名称` | `路径不存在，启动时将被跳过` |

两种图标只是显示层标记，配置里存的仍是原始路径字符串，因此旧配置可直接读取。

## 打开策略

`launch_program()` 先判断 `os.path.isdir()`：

| 平台 | 做法 |
|---|---|
| Windows | `os.startfile(目录)`，由资源管理器打开 |
| macOS | `open 目录` |
| Linux | `xdg-open 目录` |

文件夹打开后返回 `None`，**不会进入 `launched_items`**，所以「关闭所有程序」不会误杀 `explorer.exe`。
普通文件沿用原有逻辑（`WScript.Shell.Run` → 失败回退 `os.startfile`）。

## 路径规范化

`normalize_input_path()` 依次处理：

1. 去首尾空白；
2. 去掉成对的双引号或单引号（资源管理器「复制为路径」会带引号）；
3. `os.path.expandvars()` 展开 `%USERPROFILE%`、`%APPDATA%` 等；
4. `os.path.expanduser()` 展开 `~`；
5. `os.path.normpath()` 统一分隔符。

去重使用 `normcase(normpath())` 比较，`C:/a` 与 `C:\a` 视为同一条。

## 上次使用的文件夹

- 保存在 `launcher_presets.json` 的 `settings.last_folder`；
- 加入文件夹后记录该目录；加入文件后记录其所在目录；
- 用作「添加程序 / 添加文件夹」对话框的起始位置，以及「输入路径」的默认值；
- 目录已失效时自动回退到用户主目录，不会卡在无效位置。

## 已知限制

- 目录选择框一次只能选一个文件夹（文件选择框支持多选）；需要多个时重复点击或直接拖拽。
- 失效条目只是标记并跳过，不会自动清理；确认不再需要时手动删除。
- 打开文件夹不区分"新窗口 / 已有窗口"，由系统设置决定。

## 与其他功能的关系

一次「一键启动」涉及 **2 个及以上**文件夹时，不会逐个弹出资源管理器窗口，
而是由 `FEAT-006 多标签文件夹窗口` 合并到一个窗口；
只有 1 个文件夹时仍由系统资源管理器打开。
