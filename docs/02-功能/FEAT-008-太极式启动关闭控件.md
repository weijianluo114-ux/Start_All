# FEAT-008 · 太极式启动 / 关闭控件

- **状态**：已实现（待验收，目标 v1.8.0）
- **关联**：REQ-006、T-009

## 入口

主窗口**顶部居中**的圆形控件（`TaijiLaunchButton`，默认直径 132 px）。

## 行为

| 操作 | 结果 |
|---|---|
| 点左半（绿） | 一键启动当前预设，等同原「🚀 一键启动」 |
| 点右半（红） | 关闭列表内程序与文件夹窗口，等同原「⏹ 关闭全部」 |
| 点圆外 | 不响应 |
| 按下左半后拖出圆外松开 | 不触发 |
| 悬停某一半 | 该半提亮并在弧边出现高光描边 |
| 启动进行中 | 左半变灰、不可点；右半保持可用 |

## 实现

| 成员 | 说明 |
|---|---|
| `TaijiLaunchButton(直径)` | 自绘控件，两个半圆各自独立响应 |
| `run_requested` / `close_requested` | 对外信号，`LauncherWindow` 分别接到 `launch_all` / `close_all_programs` |
| `set_run_enabled(bool)` | 左半启用状态；`launch_all` 开始时置灰、结束时恢复 |
| `_side_at(pos)` | 命中判定：圆内按垂直直径分左右，圆外返回 `None` |

3D 质感由四层绘制叠加而成（全部为矢量，无图片资源）：

1. **主渐变**：`QLinearGradient` 左上亮 → 右下暗；
2. **顶部高光**：`QRadialGradient` 椭圆镜面，落在每个半圆的靠外上方；
3. **底部内阴影**：纵向渐变，压暗下缘形成厚度；
4. **落影 + 外圈**：多层低透明度椭圆做柔和阴影，外圈上亮下暗描边强化球面感。

中缝用「一条暗线 + 一条偏右亮线」做出折痕，避免整圆看起来像两张贴纸。

## 已知限制

- **只能整圆显示**：默认直径 132 px，窗口缩放时控件本身不跟随缩放（固定尺寸，避免自绘模糊）。
- **无键盘焦点**：当前仅支持鼠标点击；需要键盘操作时请改用列表与菜单（后续可补 `Tab` 焦点与回车触发）。
- **配色为固定值**：绿 `#25B45F`／红 `#D93E33`，改色需改 `RUN_COLORS` / `CLOSE_COLORS` 常量。
- 无高 DPI 位图缩放问题（纯矢量绘制），但极小的直径下文字会拥挤，建议不小于 110 px。
