# FEAT-008 · 太极式启动 / 关闭控件

- **状态**：已实现（待验收，目标 v1.8.0）
- **关联**：REQ-006、T-009

## 入口

主窗口**顶部居中**的阴阳圆盘（`TaijiLaunchButton`，默认直径 160 px）。

## 造型

按太极图的几何构造绘制，不是"一个圆对半切开"：

| 元素 | 说明 |
|---|---|
| 阴鱼（左，绿） | 外圈左半弧 + 上段 S（上方小圆的右半）+ 下段 S（下方小圆的左半），头部在上 |
| 阳鱼（右，红） | 外圈右半弧 + 同样的 S 曲线，头部在下 |
| 缝隙 | 沿 S 曲线用 `QPainterPathStroker` 从两条鱼各切掉一半，形成 4 px 真实间隙；**缝内只透面板底色**，不加任何投影 |
| 鱼眼 | 左鱼嵌红点、右鱼嵌绿点，位置在各自鱼头中心 |
| 文字 | 「启动」「关闭」两字**竖排**（逐字居中、自上而下），不做旋转，分别落在两条鱼的鱼身上 |

## 行为

| 操作 | 结果 |
|---|---|
| 点绿色鱼身 | 一键启动当前预设，等同原「🚀 一键启动」 |
| 点红色鱼身 | 关闭列表内程序与文件夹窗口，等同原「⏹ 关闭全部」 |
| 点缝隙 / 圆外 | 不响应（缝隙是真实间隙，`QPainterPath.contains()` 判定） |
| 按下后拖出鱼身再松开 | 不触发 |
| 悬停某条鱼 | 该鱼提亮，轮廓出现高光细边 |
| 启动进行中 | 绿鱼变灰、文字转深灰、不可点；红鱼照常可用 |

## 视觉实现（全部矢量，无图片资源）

1. **主体渐变**：`QLinearGradient` 左上亮 → 右下暗，统一光源方向；
2. **顶部镜面高光**：`QRadialGradient` 落在左上，模拟环境光；
3. **底部内阴影**：纵向渐变压暗下缘，形成厚度；
4. **边缘浮雕**：沿鱼形轮廓用**对角渐变画笔**描边（左上白、右下黑），这是"凹凸感"的主要来源；
5. **盘心发光**（v1.8.0）：两条鱼各叠一层「自身颜色 `lighter(124)`」的径向渐变
   （中心 alpha 86 → 0），再叠一层跨缝白色柔光（中心 alpha 44）；
   注意**不能直接叠纯白**，否则玉绿会被冲成灰绿；
6. **外圈包边**：整圆左上亮、右下暗的 2.2 px 环，把圆盘"托"在面板上；
7. **落影**：多层低透明度椭圆叠出柔和阴影（不依赖模糊滤镜）。

## 实现要点

| 成员 | 说明 |
|---|---|
| `_geometry()` | 一次性算出圆框、两条鱼路径、鱼眼位置；绘制与命中判定**共用同一份几何** |
| `_side_at(pos)` | `path.contains()` 判定，天然支持 S 形边界与缝隙 |
| `_paint_fish()` | 渐变 + 高光 + 内阴影 + 浮雕描边 + 悬停细边 |
| `_paint_core_glow()` | 盘心发光：自身色径向提亮 + 跨缝白色柔光，`setClipPath` 裁在圆内 |
| `_paint_eye()` | 鱼眼：投影 + 渐变球体 + 浮雕边 |
| `_paint_bezel()` | 外圈包边 |
| `_paint_text()` | 竖排文字，逐字绘制（启用态白字带暗影，禁用态深灰字） |

## 已知限制

- **尺寸固定**：绘制与命中都基于初始化时的直径（160 px），窗口缩放不会改变圆盘大小；
  需要改大小就改 `TaijiLaunchButton(160)` 这个参数。
- **缝隙不可点**：S 曲线上 4 px 的间隙属于"空档"，故意不响应点击（避免误触另一半）。
- **缝隙不加深色投影**：缝本身透面板底色，靠盘心的光把两块区分开；
  早期版本在缝里压过一道黑影，放大后像一条发黑的深沟，已移除。
- **鱼形边界靠矢量判定**：窗口在极高 DPI 缩放下依旧准确（`contains()` 基于路径而非像素），
  但若将来把圆盘改成图片资源，边界必须同步维护。
- **无键盘焦点**：目前仅鼠标操作。
