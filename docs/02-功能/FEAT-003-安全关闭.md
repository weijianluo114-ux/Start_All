# FEAT-003 · 安全关闭所有程序

- **状态**：可用
- **首次版本**：v1.3.0
- **最近变更**：v1.4.1（BUG-002 修复：镜像名兜底 + 日志）
- **关联需求**：REQ-002
- **代码位置**：`LauncherWindow.close_all_programs()` 及其私有方法（`_get_process_map` / `_close_targets` / `_find_launched` / `_pid_info` / `_kill_target` / `_taskkill` / `_wait_until_gone` / `_elevated_kill`）

## 它做什么

把列表里**正在运行**的程序一次性关掉。先确认、再检测、能关才关、关完给结果，且不退出启动器。

## 交互流程

```
点击 ⏹ 关闭所有程序
   ├─ 列表为空 ──────────────→ 提示"列表为空"，结束
   ├─ 只有文件夹 ────────────→ 提示"没有需要关闭的程序"，结束
   ├─ 采集进程快照 → 分类
   │     ├─ 无任何运行中 ────→ 提示"无需关闭"，结束（不弹确认框）
   │     └─ 有运行中 ────────→ 确认框（默认「否」，列出程序名）
   │              ├─ 否 ─────→ 直接返回，不做任何操作
   │              └─ 是 ─────→ 逐项关闭（PID → 镜像名）→ 轮询复查（≤3s）
   │                              ├─ 成功 ─→ 计入已关闭
   │                              └─ 仍失败 ─→ 若为"拒绝访问"，可选用管理员权限重试
   └─ 不关闭启动器本身
```

## 判定规则

| 条目情况 | 处理 |
|---|---|
| 本次会话启动过，且 PID 存活、镜像与目标一致 | 先按 PID 关闭（`/t` 杀进程树） |
| 本次会话启动过，但 PID 已失效 | 记录日志，转由镜像名关闭（单实例应用的典型情况，见 BUG-002） |
| 镜像名等于启动器自身 | 跳过（避免自杀） |
| 镜像名在进程快照中 | 关闭（按 `/im`） |
| 不在快照中 | 跳过，理由"未运行" |
| `.bat/.cmd` 且非本次启动 | 跳过，理由"无法判定"（进程名是 `cmd.exe`） |
| 路径已失效（`⚠`） | 跳过，理由"路径已不存在" |
| 文件夹 | 不参与关闭 |

> 关键点：**镜像名关闭是无条件执行的兜底**，不是 `elif` 分支。否则一旦记录的 PID 失效，程序就永远关不掉。

## 结果汇总

关闭后轮询复查（最长 3 秒，每 250 ms 一次），提示形如：

```
已关闭 2 个程序。
跳过 3 项（未运行 / 无法判定）。

关闭失败 1 项：
· xxx.exe —— 权限不足（需管理员）

详细命令与返回码已写入日志：
C:\Users\<用户>\AppData\Local\MultiLauncher\logs\launcher.log
（可点击主界面「🗒 日志」打开所在目录）
```

失败原因分为两类：`权限不足（需管理员）`、`进程仍在运行（可能被后台服务重启）`。

## 日志

- 位置：`%LOCALAPPDATA%\MultiLauncher\logs\launcher.log`，按 1 MB 轮转、保留 3 份。
- 记录内容：启动版本与环境、每个条目的启动结果（PID / 解析路径）、关闭判定结果（运行中 / 跳过及理由）、
  每条 `taskkill` 命令与退出码、原始输出（GBK 解码）、每个目标的步骤明细、最终统计。
- 未捕获异常与线程异常也会写入，便于 GUI 模式下排查。
- 主界面「🗒 日志」按钮直接打开日志目录。

## 实现要点

- 进程快照用 `tasklist /fo csv /nh` + `csv.reader` 解析，避免程序路径含逗号导致错列。
- 关闭前会置 `_stop_launch = True` 并 `join(1)`，避免"一边启动一边关闭"打架。
- `_pid_info()` 同时返回"是否存活"与"镜像名"：既判断 PID 有效性，也防止 PID 被系统复用后误杀无关进程。
- 结束后 `launched_items.clear()` 并 `save_config()`，避免残留已死 PID。
- 检测到"拒绝访问"且进程仍在时，提示可用管理员权限重试（把若干 `taskkill` 写入临时批处理，`ShellExecuteW runas` 执行一次，只弹一次 UAC，随后轮询验证）。

## 已知限制

- **按镜像名关闭会命中同名全部实例**：列表里放一个 `chrome.exe`，会把系统里所有 Chrome 关掉。这是 `/im` 的语义，属于预期行为；确认框会显示程序名，请据此判断。
- `.bat/.cmd` 若非本次启动，无法安全判定，宁可不关。
- 单实例应用（Electron / Tauri 等）重复启动时，记录的 PID 会立即失效；本版本已由镜像名兜底覆盖，详见 BUG-002。
