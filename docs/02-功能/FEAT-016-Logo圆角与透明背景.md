## 成品几何（实测）

| 项 | 值 |
|---|---|
| 黑框外沿 | `(48.9, 78.8) – (700.0, 709.1)`，边框厚约 43px（与 v1.15.0 一致） |
| 圆角半径 | 72px（外沿处），内沿约 31px |
| 透明区 | 黑框圆角矩形以外的全部米白（约 199,639 px） |
| 箭头穿出段 | `x 700..738, y 397..452`，按自身边缘取 alpha，尖端收干净 |
| 半透明像素 | 2,231 px，全部在边缘，颜色均为黑框/箭头的抗锯齿混色 |

## 实现要点（`scripts/make_logo.py`）

1. **几何测量**：`measure()` 用 0.5 覆盖率交叉点亚像素定位外框/内框
   （投影到「米白→黑」色轴，黄色箭头不会误当边框）。
2. **圆角遮罩**：8 倍超采样画 `rounded_rectangle`，BOX 降采样得面积平均抗锯齿。
3. **alpha 合成**：`alpha = min(圆角遮罩, 源图覆盖率)`；箭头穿出段（`x ≥ x1-1`）
   豁免圆角遮罩，只按覆盖率取值；「圆角矩形内缩 2px」整块补实框内区域。
4. **去白边**：`unmix_edge_color()` 按 `fg = (obs − (1−α)·bg) / α` 反解前景色，
   低 alpha 过冲的离群像素吸附到最近的实心色（黑框 / 箭头黄）。
5. **ICO 打包**：预乘 alpha 后缩放（780→16/32 用 BOX 防止黑框被米白"洗"灰，
   256 用 LANCZOS 保锐度），≤128 写 32bpp BMP 帧、256 写 PNG 帧。

## 已知限制

- 框内米白底保留不透明是**设计要求**（REQ-016），深色背景上 icon 中心仍是一块
  米白——这是原画的构图，不是漏改；
- 16px 下边框厚仅 0.84px，圆角在最小档与直角视觉无差别（所有图标同理）；
- 若日后更换源稿，重跑 `scripts/make_logo.py` 即可，半径等参数在文件头常量区。
