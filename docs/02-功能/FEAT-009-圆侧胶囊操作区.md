# FEAT-009 · 圆侧胶囊操作区

- **状态**：可用（v1.9.0）
- **关联**：REQ-008、FEAT-008、`PillButton` / `PillColumn`

## 入口与位置

| 位置 | 左列 | 右列 |
|---|---|---|
| 上端 | 添加文件夹 | 删除选中 |
| 与圆心齐平 | 添加程序 | 日志 |
| 下端 | 输入路径 | 设置（v1.10.0 起打开设置面板） |

「新建 / 删除」预设仍在上方预设行，使用同款小号胶囊。

## 行为

| 操作 | 结果 |
|---|---|
| 添加程序 | 打开文件选择框，多选加入当前预设 |
| 添加文件夹 | 打开目录选择框，可多选；记住上次目录 |
| 输入路径 | 弹输入框，手工粘贴路径（支持引号、8.3 短名，自动解析 `.lnk`） |
| 删除选中 | 删除列表中选中的条目（不改文件，只从预设移除） |
| 日志 | 打开 `%LOCALAPPDATA%\MultiLauncher\logs` |
| 设置 | 打开设置面板（开机自启动开关，见 FEAT-010） |

## 实现要点

1. **宽度成对给定**（v1.9.0 / REQ-009）：`sizeHint` 只用来算基准宽度
   （`fontMetrics.horizontalAdvance(文本) + 内边距×2`），实际宽度由 `LauncherWindow` 统一决定——
   上/下排取 `w_outer = max(添加文件夹, 删除选中, 输入路径, 设置)`，
   中排取 `w_mid = max(添加程序, 日志)`，左右两列共用同一组值。
   结果：上 111 / 中 96 / 下 111，左右逐排等长、上下镜像。
2. **位置规则**：`PillColumn` 用绝对定位，三枚中心分别位于 `列中心 − 66 / 列中心 / 列中心 + 66`，
   所以中间那枚与圆心严格齐平（`T-010` 用断言守住这条，防止以后被布局改写）。
3. **外侧对齐**：左列 `x = 0`（三枚左缘同一条线），右列 `x = 列宽 − 按钮宽`（三枚右缘同一条线）；
   两列都朝外对齐、朝圆一侧参差，与"内外圆角"的方向一致。
4. **内外圆角呼应**：`border-{四角}-radius` 独立设置，朝外一侧 `8px`、朝圆一侧 `19px`（= 高度一半）。
   左列收左边、右列收右边。
5. **边框统一**：四边同为 `#BEAD86`，不再给上下沿单独上色——早期版本的白色上沿在浅色面板上像一道亮缝。
6. **质感**：竖向渐变（白 → 象牙白 → 米金）承担压铸感；hover 提亮并转金边，pressed 反向压暗。
7. **三层明度**：暖白面板 `#EDE7DB` → 象牙白胶囊 → 纯白列表，浅色系也能拉出层次。

## 已知限制

- 胶囊宽高按像素写死（38 / 内边距 18），在 150% 缩放下会显得偏小；如需适配高 DPI，应改为按
  `devicePixelRatio` 缩放，不在本版范围内。
- 宽度只有两档（外排 111 / 中排 96），不再逐条按字数变化——这是 REQ-009 为"左右与上下对称"
  付出的代价；六条全等宽只需把 `row_widths` 改成三个相同值。
- 六项操作的顺序写死在 `LauncherWindow.__init__` 里，没有做"用户自定义位置"。
- 「设置」在 v1.9.0 是空入口；v1.10.0 起接入真实设置面板（REQ-010 / FEAT-010）。
