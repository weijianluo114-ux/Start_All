# FEAT-009 · 圆侧胶囊操作区

- **状态**：可用（v1.9.0）
- **关联**：REQ-008、FEAT-008、`PillButton` / `PillColumn`

## 入口与位置

| 位置 | 左列 | 右列 |
|---|---|---|
| 上端 | 添加文件夹 | 删除选中 |
| 与圆心齐平 | 添加程序 | 日志 |
| 下端 | 输入路径 | 设置（占位，未实现） |

「新建 / 删除」预设仍在上方预设行，使用同款小号胶囊。

## 行为

| 操作 | 结果 |
|---|---|
| 添加程序 | 打开文件选择框，多选加入当前预设 |
| 添加文件夹 | 打开目录选择框，可多选；记住上次目录 |
| 输入路径 | 弹输入框，手工粘贴路径（支持引号、8.3 短名，自动解析 `.lnk`） |
| 删除选中 | 删除列表中选中的条目（不改文件，只从预设移除） |
| 日志 | 打开 `%LOCALAPPDATA%\MultiLauncher\logs` |
| 设置 | **占位**：只弹"设置面板尚未实现"，不改任何配置 |

## 实现要点

1. **宽度按字数算**：`PillButton.sizeHint()` = `fontMetrics.horizontalAdvance(文本) + 内边距×2`，
   因此「日志」(86px)、「添加程序」(96px)、「添加文件夹」(111px) 自然形成长短差。
2. **位置规则**：`PillColumn` 用绝对定位，三枚中心分别位于 `列中心 − 66 / 列中心 / 列中心 + 66`，
   所以中间那枚与圆心严格齐平（`T-010` 用断言守住这条，防止以后被布局改写）。
3. **贴圆对齐**：左列右对齐、右列左对齐，两列都朝圆的方向收拢，中间留 12px 呼吸位。
4. **质感**：`border-radius = 高度/2` 得到完整胶囊；上沿亮边 + 下沿暗边 + 竖向渐变模拟压铸；
   hover 提亮并转金边，pressed 反向压暗。
5. **三层明度**：暖白面板 `#EDE7DB` → 象牙白胶囊 → 纯白列表，浅色系也能拉出层次。

## 已知限制

- 胶囊宽高按像素写死（38 / 内边距 18），在 150% 缩放下会显得偏小；如需适配高 DPI，应改为按
  `devicePixelRatio` 缩放，不在本版范围内。
- 六项操作的顺序写死在 `LauncherWindow.__init__` 里，没有做"用户自定义位置"。
- 「设置」是空入口；点击会明确提示尚未实现，避免被误认为按钮失效。
