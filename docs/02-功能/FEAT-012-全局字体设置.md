# FEAT-012 · 全局字体设置

- **状态**：可用（v1.12.0）
- **范围**：设置面板 → 字体卡片；主窗口全部文字；圆盘文字（有限跟随）
- **关联**：REQ-012、REQ-011、REQ-010
- **代码**：`FONT_PRESETS` / `FontPrefs` / `ui_font()` / `set_ui_font()` / `restyle_widgets()` /
  `CardFrame` / `SizeSlider` / `SettingsDialog._apply_fonts()`

## 入口

「设置」胶囊 → 弹窗第二张卡片：

```
┌─ 设置 ─────────────────────────────────┐
│ [开机自启动 ↗]                          │
│ ┌─────────────────────────────────────┐ │
│ │ 字体搭配 [雅黑 × 思源（默认） ▾]     │ │
│ │ 标题思源、正文雅黑 · 当前默认观感 · 本机可用 │
│ │ ┌ 一键多启 · LaunchForge 2026 ─────┐ │ │
│ │ └──────────────────────────────────┘ │ │
│ │ 字号  ●─────────────────────  13 px │ │
│ └─────────────────────────────────────┘ │
│ 未启用 · 开启后随 Windows 登录启动      │
│                                  [关闭] │
└─────────────────────────────────────────┘
```

改动即时生效并写入 `%LOCALAPPDATA%\MultiLauncher\launcher_presets.json` 的 `settings`，
没有「保存」按钮（与自启动开关的行为一致）。

## 五套推荐搭配

| 搭配 | 标题家族 | 正文字族 | 适用 |
|---|---|---|---|
| 雅黑 × 思源（默认） | Noto Sans SC → 雅黑 UI | 微软雅黑 UI | 当前默认观感，标题更利落 |
| 雅黑经典 | 微软雅黑 UI | 微软雅黑 UI | 只用系统自带字体，最稳妥 |
| 等线清朗 | 等线 / DengXian | 等线 / DengXian | 字形偏瘦、字面更高，同字号更透气 |
| 中英分排 | Segoe UI → 雅黑 | Segoe UI → 雅黑 | 西文数字用 Segoe UI，中文回落雅黑 |
| 书卷衬线 | Noto Serif SC → 宋体 | 微软雅黑 UI | 标题衬线、正文黑体，气质更文气 |

- 每套都是一条**候选链**，只挑本机已安装的家族；全部缺失时回退到雅黑 UI。
- 卡片里那行小字会显示当前搭配的说明，并标注「本机可用」或「未安装，回退到 xxx」。
- 悬停下拉项可见该搭配的推荐理由（`Qt.ToolTipRole`）。

## 字号：11–17px，等比缩放

`FontPrefs.SIZE` 存的是**正文基准**，其余角色按同一倍率换算，级差固定：

| 角色 | 基准 13px | 最小 11px | 最大 17px |
|---|---|---|---|
| 设置标题（display 17） | 17 | 14 | 22 |
| 卡片标题（title 14） | 14 | 12 | 18 |
| 正文 / 列表 / 胶囊（13） | 13 | 11 | 17 |
| 预设标签（12） | 12 | 10 | 16 |
| 说明文字（11） | 11 | 10（下限） | 14 |

- 最小值 10px 是硬下限：再小中文笔画会糊，且与「清晰可读」的目标冲突。
- 圆盘里的「启动 / 关闭」由盘面直径推导，只跟随 **0.94–1.16 倍**：
  圆盘是插画，字号无限跟随会压到 S 形缝隙与盘沿。
- 类型图标里的 `!` 固定 9px：它长在 18×18 的固定几何里，跟随缩放会顶出三角。

## 两端极值的布局保障

| 位置 | 保障方式 | 11px | 17px |
|---|---|---|---|
| 胶囊宽度 | `sizeHint()` 按 `fontMetrics` 实算，列宽取最长一条 | 92 | 122 |
| 胶囊高度 | 固定 38 / 28，均 ≥ 文字高 + 4 | 38 | 38 |
| 预设行 | 下拉 `minimumHeight = 字高 + 12`，胶囊宽度随文字 | 30 | 38 |
| 列表行高 | `max(34, 字高 + 17)` | 34 | 34 |
| 设置卡片 | `SettingRow.sync_height()` 按行数实算 | 90 | 97 |
| 设置面板 | 宽度固定 420，高度 `layout.heightForWidth()` 实算 | 396 | 438 |
| 说明文字 | `wordWrap = True`，宁可变高不裁字 | — | 换行 |

`docs/images/settings-fonts-min-max.png`（设置面板）。
打包后的真实产物见 `docs/images/real-window-v1.12.0.png`（默认 13px）、

## 即时生效的实现

```python
set_ui_font(widget, 13, QFont.Normal, 'text', 0.2)   # 设字体 + 记录基准 spec
...
FontPrefs.set(key=..., size=17)                      # 改偏好（会清家族缓存）
restyle_widgets(root)                                # 遍历控件树，按 spec 重建字体
window._relayout_pills()                             # 宽度重算（字号变了宽度也变）
window.list_widget.refresh_row_fonts()               # delegate 不是 QWidget，单独刷新
```

**为什么不重建主窗口**：`launched_items` 保存着"文件类条目 → 关联程序 PID"的线索，
重建窗口会丢这份状态，表现为"改完字号后，刚打开的文件关不掉了"。
走 spec 重建这条路，业务状态一点不动。

## 存储与兼容

```json
{
  "settings": {
    "last_folder": "E:\\work",
    "font_key": "classic",
    "font_size": 13
  }
}
```

- 旧配置没有这两个键 → 用默认值（`classic` / 13），观感与 v1.11.0 完全一致；
- 键值被手改坏（`font_key: "???"`、`font_size: 99`）→ 收敛到第一套 / 17px，不阻断启动；
- 只在设置面板改动时写盘，其他路径（加条目、切预设）会原样带上当前值。

## 已知限制

- **只能选本机已安装的字体**：不内置字体文件，缺字体时只能回退。
- **下拉项不显示两行说明**：弹出列表用系统默认绘制，说明放在 tooltip 与选中后的说明行里。
- **窗口只涨不缩**：字号调回小档时主窗口保持当前尺寸（用户可能已手动拉大），不突然收缩。
- **系统对话框不受影响**：`QMessageBox` / 文件选择框走系统字体，不跟 `FontPrefs`。
