# FEAT-007 · 关闭文件夹窗口

- **状态**：已完成（v1.7.0）
- **关联**：REQ-005、Q-003、T-008

## 入口

主界面「⏹ 关闭全部」（原「关闭所有程序」，v1.7.0 起同时处理文件夹窗口）。

## 行为

1. 读取列表条目，分成**程序**与**文件夹**两类。
2. 程序：照旧按"启动记录 PID → 镜像名兜底"关闭，未运行的跳过。
3. 文件夹：枚举当前资源管理器窗口，按路径把列表条目对应到窗口（同一窗口的多个标签合并判定）：

   | 窗口情况 | 处理 |
   |---|---|
   | 窗口内所有标签都在列表内 | 主确认框列出，确认后**整窗关闭** |
   | 窗口混有列表外标签 | 主确认框之后**单独询问一次**：同意整窗关，不同意跳过 |
   | 列表内的文件夹没有打开的窗口 | 跳过，结果里说明数量 |

4. 汇总：`已关闭 N 个程序` / `已关闭 M 个文件夹窗口` / `跳过 K 项` / 失败项及原因。

## 实现

| 函数 | 说明 |
|---|---|
| `list_explorer_windows()` | `Shell.Application.Windows()` 枚举，按 `HWND` 分组；类名过滤 `CabinetWClass` |
| `_norm_fs_path()` | 路径归一化（`normcase` + `normpath`；`::` 虚拟位置不参与匹配） |
| `_folder_window_plan()` | 输出 `closable`（可整窗关）与 `mixed`（含列表外标签，附 `foreign` 列表） |
| `_close_folder_window()` | `WM_CLOSE` 循环 + 逐次复查；`attempts` / `remaining` 写入日志 |
| `_window_label()` | 生成"Alpha、Bravo（2 个标签）"这类可读标识 |

关闭顺序：`WM_CLOSE` 每次关掉**当前活动标签**，窗口条目数随之减少，循环到窗口消失为止；
单标签窗口一次即整窗消失。若连续两次标签数不减少，判定为关不动（被拦截/无响应），
立即停止并报失败，不空转。

## 已知限制

- **无法只关窗口中的某一个标签**：系统未提供稳定接口，只能整窗关闭。
- **混合标签窗口默认不关**：须用户在询问框里点「是」；这是刻意设计，避免连带关掉无关标签。
- **Windows 11 标签页专属**：Windows 10 没有标签页，每个窗口一个文件夹，等价于"单标签窗口"。
- **不结束 `explorer.exe`**：只发窗口关闭消息，任务栏与其余窗口不受影响。
- 需要 `pywin32`（项目依赖已包含）；缺失时文件夹窗口会被跳过，并在日志中说明。
