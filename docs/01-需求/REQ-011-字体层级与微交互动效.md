# REQ-011 · 字体层级与微交互动效

- **状态**：已完成（v1.11.0）
- **提出**：2026-10-21
- **关联**：FEAT-011、REQ-006（圆盘）、REQ-009（胶囊）

## 背景

v1.10.0 的界面能用，但两处"朴素"：

1. **字体**：全界面只用 `Microsoft YaHei UI` 一个家族、Regular/Bold 两档字重，13–15px 混用，
   层级只靠大小区分，中文在 15px 下显得钝；
2. **交互**：所有悬停都是 QSS 的 `:hover` **瞬时切换**，没有过渡；列表行 hover 也是瞬间变色，
   按下没有"键程"反馈。观感是"能点"，但没有"有回应"。

要求：在不改布局的前提下，让字体和悬停互动显得更精致、更有回应感。

## 期望行为

1. 建立一套可复用的设计令牌（颜色 / 字号 / 字重 / 时长），后续新增控件直接取用；
2. 字体按"首选 → 回退"解析，本机有更好字体时用更好的，缺失时安全降级；
3. 悬停、按下、选中都**逐帧过渡**，不跳变；过渡只触发重绘，不触发布局；
4. 动效时长符合业界区间：悬停 80–120ms、按下 80–100ms，统一 ease-out；
5. 尊重系统「动画效果」开关：关掉后过渡压到 1ms，只保留最终状态；
6. 布局、控件位置、点击区域一律不变。

## 实现方式

| 项 | 做法 |
|---|---|
| 令牌 | 新增 `Theme`（颜色 / 时长 / 动画开关）与 `ui_font(size, weight, kind, spacing)` |
| 字体解析 | `_resolve_family()` 按家族候选表挑第一个已安装的，结果缓存；`display` 首选 Noto Sans SC，`text` 首选雅黑 UI |
| 字重 | 只用 400 / 600 / 700 三档，中文正文不用细体 |
| 胶囊 | 弃用 QSS，改 `QPainter` 自绘 + `hover_t` / `press_t` 两个动画属性 |
| 列表 | 自绘 `ListRowDelegate` + `AnimatedList` 的 16ms 补间器（逐行 hover / select 值） |
| 圆盘 | 悬停强度 `hover_t` 补间，驱动外发光与调色；不再瞬间提亮 |

## 关键取舍

### 1. 为什么胶囊要放弃 QSS

QSS 的 `:hover` 无法过渡；若用定时器反复重设 `styleSheet`，每次都会触发整棵样式树重算，
6 枚按钮 × 60fps 的代价不可接受。自绘后动画只是改两个 float 并 `update()`，
只重绘自己，且天然不触发布局。

代价是样式不再能靠文本搜索验证，因此把"四角半径"抽成 `corner_radii()` 作为公开契约，
测试从"查样式表字符串"改为"查几何定义"（语义不变）。

### 2. 为什么列表用补间器而不是每行一个 QPropertyAnimation

行会增删（添加条目、删预设、拖拽），每行一个动画对象就要管理生命周期与销毁。
用一个 16ms 补间器统一推进，行数变化零成本；缓动指数 0.30 约等于 110ms 收敛，
与按钮的悬停时长一致，整体"手感"统一。

### 3. 边框仍保持四边同色

REQ-009 明确要求过"去掉上沿白线"。这一版做金属质感时曾试过"上亮下暗"的渐变描边，
虽然更像压铸件，但等于把那道白线请了回来，因此改为：**四边同色 + 悬停整体加深**，
层次交给内侧 1px 高光、底缘反光与衬底渐变。

### 4. 列表类型改用矢量图形，不用 emoji

原来 `📁` / `⚠` 由 `entry_label()` 拼进文字。emoji 在本机的彩色渲染与暖色 + 金 的
整体调性冲突，且不同系统版本字重不一致。改为 delegate 绘制 18×18 矢量图形
（文件夹 / 可执行 / 普通文件 / 失效），而 `entry_label()` 的文本保持不变——
现有测试与配置仍按原样工作。

## 验收标准

- [x] `ui_font()` 按角色返回正确家族/字号/字重/字距；缺失字体时回退不报错
- [x] 悬停强度在 45ms 处于中途（0 < t < 0.98），205ms 到达 1.0
- [x] 悬停前后像素差 > 300；悬停边框颜色明显加深
- [x] 按下强度到达 1.0 且与悬停态有明显像素差；松开回落
- [x] 列表 hover / select 均补间到 1.0，移出后 hover 归零而 select 保持
- [x] 类型分类 dir / exe / file / missing 正确；emoji 前缀可剥离
- [x] 圆盘悬停发光补间，移出归零
- [x] 系统关闭动画后时长为 1ms，恢复后回到 110ms
- [x] 布局与点击区域未变：T-001～T-012 全部通过

## 决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-21 | 悬停 110ms / 按下 90ms | 业界区间是悬停 80–120、按下 80–100；按下必须比悬停更快才有"键程"感 |
| 2026-10-21 | 缓动统一 OutCubic | 起步快、收尾慢，符合"元素被指向 = 进入"的语义 |
| 2026-10-21 | 字号从 15px 降到 13px 并加 0.3 字距 | 中文在 15px 下笔画偏钝；13px + 轻微字距更紧致，也让胶囊变短（111→102） |
| 2026-10-21 | 列表行高 34px、行块圆角 8px | 视觉节奏与胶囊（38/19）同族但更小，避免列表抢主视觉 |
| 2026-10-21 | 保留 emoji 文本但不再绘制 | 兼容现有测试与配置；显示层单独升级，互不牵连 |
