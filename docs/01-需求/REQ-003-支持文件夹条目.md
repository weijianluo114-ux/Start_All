# REQ-003 · 支持文件夹条目

- **状态**：已完成（v1.4.0）
- **提出日期**：2026-10-19
- **完成日期**：2026-10-19
- **目标版本**：v1.4.0
- **关联**：FEAT-002、FEAT-005、T-003

## 背景

原版列表只接受可执行文件（`.exe/.lnk/.bat/.cmd`），拖入文件夹会被 `dropEvent` 的
`os.path.isfile()` 过滤掉。用户希望把常用工作目录也编进预设，一键打开。

## 期望行为

1. 可以把**文件夹**加入列表，并与程序混排。
2. 文件夹条目参与「一键启动」：用资源管理器打开该目录。
3. 三种添加方式都支持：
   - 拖拽文件夹到窗口 / 列表
   - 按钮选择（目录选择对话框）
   - 手动输入路径（支持粘贴，非法路径要给出提示）
4. **记住上一次使用的文件夹地址**：下次打开选择框时定位到该目录；手动输入时作为默认值。
5. 双击文件夹条目 → 打开该目录。
6. 「关闭所有程序」跳过文件夹（不尝试结束 explorer）。

## 决策记录

| 待确认项 | 决定 | 理由 |
|---|---|---|
| 显示方式 | `📁 名称`，tooltip 显示「文件夹 + 完整路径」 | 一眼区分"会开窗口"还是"会开目录"，比纯名称更少误点 |
| 打开方式 | `os.startfile(目录)` 打开目录本身 | 需求是"打开文件夹"，不是"定位到其中某个文件"；`explorer /select` 需要文件级目标 |
| 目录不存在 | 列表内以 `⚠` 保留并可提示，启动时跳过；手动输入时直接拒绝 | 保留条目避免"U 盘没插就被永久删掉"；启动时跳过避免一次失败中断整批 |
| 环境变量 | 支持 `%USERPROFILE%`、`~`，并自动去掉成对引号 | 资源管理器「复制为路径」会带引号，粘贴后不该报错 |

## 实现要点

- **存储结构不变**：条目仍是路径字符串，运行期用 `os.path.isdir()` 判定类型，旧配置无需迁移。
- `launch_program()` 增加目录分支，打开后返回 `None`（不产生需要管理的子进程）。
- `dropEvent` 的存在性判断由 `os.path.isfile` 放宽为 `os.path.exists`，文件夹即可拖入。
- 新增 `normalize_input_path()`：去空白 / 去引号 / 展开环境变量 / `normpath`。
- 新增 `entry_kind()` / `entry_label()` / `entry_tooltip()`：统一决定图标与提示。
- 新增 `settings.last_folder`：目录选择框起始位置、手动输入默认值。
- `load_current_preset_list()` 不再丢弃失效路径，改为 `⚠` 展示，避免下一次保存把预设永久清空。
- `close_all_programs()` 先过滤掉文件夹；只有文件夹时直接提示，不进入确认流程。
