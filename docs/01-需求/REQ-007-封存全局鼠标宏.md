# REQ-007 · 封存全局鼠标宏

- **状态**：已完成（v1.9.0）
- **提出**：2026-10-20
- **关联**：FEAT-004、`src/legacy/macro_feature.py`

## 背景

宏功能（录制一段鼠标轨迹，启动后自动回放）自还原基线起就存在，但它的固有问题一直无法通过小改动解决：

1. 录制的是**屏幕绝对坐标**，窗口位置、分辨率、显示缩放一变就点偏；
2. 只录鼠标，不录键盘，输入类操作录不进去；
3. 录制时点击「停止录制」这一下本身也会被录进末尾，回放会多点一次；
4. 与"一键启动"耦合：启动完成 2 秒后自动回放，用户无法中途取消。

## 期望行为

1. 界面上不再出现任何宏入口（录制 / 播放 / 清除三个按钮全部下线）；
2. 运行时不再加载 `pynput`，也不再有 `global_macro` 字段；
3. **源码保留**：宏的完整实现移出主文件，作为可恢复的封存模块；
4. 打包时**不收集**该模块（exe 里不含它），恢复时才重新接入。

## 实现方式

| 项 | 做法 |
|---|---|
| 代码位置 | `src/legacy/macro_feature.py`（`MacroRecorderDialog` + `play_macro`） |
| 与主程序的关系 | 主程序**不 import** 它 → PyInstaller 的依赖分析扫描不到，不会打包 |
| 依赖 | `requirements.txt` 移除 `pynput`；主程序顶部不再尝试导入 |
| 配置 | 移除 `global_macro` 字段；旧配置文件里的该字段被忽略（`dict.get` 语义，不报错） |
| 恢复步骤 | 写在封存模块的文档字符串里（三步） |

## 验收标准

- [x] 界面无录制 / 播放 / 清除宏按钮
- [x] `launchforge` 模块里不存在 `MacroRecorderDialog`，窗口对象无 `global_macro`
- [x] `sys.modules` 中不出现 `macro_feature`
- [x] `src/legacy/macro_feature.py` 存在且可独立导入（`HAS_PYNPUT=True`）
- [x] 启动流程不再有"启动后自动回放"分支
- [x] 旧配置文件（含 `global_macro`）能正常加载，不报错

## 决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-20 | 采用"抽离到 `src/legacy/` 且不 import"，而非"原地加开关" | 开关方案下宏代码仍被打进 exe；抽离后连字节码都不进产物，exe 更小、依赖更干净 |
| 2026-10-20 | 保留完整源码而不是删除 | 功能本身可用，只是当前定位不需要；删掉以后再想恢复就得重写 |
