# REQ-015 · 品牌图标（最终 logo）

- **状态**：已完成（v1.15.0）
- **提出**：2026-10-21
- **目标版本**：v1.15.0
- **关联**：FEAT-015、T-019

## 背景

程序此前用的是仓库里的占位图标（`assets/logo.ico`，2026-10-19 生成），
与产品没有明确关系。用户已确认最终 logo 稿，要求替换并据此发一版。

新稿是「黑框 + SA + 黄色箭头」的方形标记，配色（黑 / 暖黄 / 米白底）
与界面现有的暖色面板、金色描边同族，可直接沿用。

## 素材

| 项 | 值 |
|---|---|
| 源文件 | `design\LaunchForge-logo_assets\c5bed955-miora_edit_image-…png`（1024×1024，RGB） |
| 主体包围盒 | `x 184..873, y 193..827`（方框 + 右侧箭头） |
| 背景色 | `#F1EBDE`（四角一致，无渐变） |
| 问题 | 右下角有「AI生成 WORKBUDDY」水印，位于 `y ≥ 930`、`x ≥ 780` |

## 期望行为

1. 用这份稿作为**唯一**图标来源：exe 文件图标、窗口标题栏、任务栏、
   资源管理器、桌面快捷方式全部一致；
2. 必须**去掉水印**——正式发布物里不能带「AI生成 WORKBUDDY」字样；
3. 单文件 ICO 内含 `16 / 24 / 32 / 48 / 64 / 128 / 256` 七档，
   覆盖标题栏（16）、任务栏（24/32）、大图标视图（48/256）等场景；
4. 小尺寸仍可辨认：16px 下要能看出「方框 + SA + 黄色元素」，
   不能糊成一个黑块；
5. 保留方形构图，不改变比例，也不加外部圆角（Windows 自己会处理）；
6. 母版 PNG 一并入库，方便日后重新生成，也让 README 有可引用的图；
7. 构建脚本与 CI **必须用同一份 ico**，不能出现"界面换了、exe 没换"。

## 不在本次范围

- 不改界面配色与布局（只换图标资源）；
- 不做多主题图标（浅色/深色系统各一套）；
- 不重画 logo 本身（用户给定稿）；
- 不为 Android / macOS 生成 `.icns` 等多平台资源。

## 验收标准

- [x] `assets/logo.ico` 含七档尺寸，每帧正方形且字节数合法
- [x] 256px 帧为 PNG 压缩（32bpp BMP 的 256 帧体积过大）
- [x] `assets/logo.png` 780×780、正方形、外圈留白、**无水印**
- [x] 源码运行时主窗口 `windowIcon()` 非空，且含 256px 档
- [x] `build.bat` 与 `build.yml` 都引用 `assets/logo.ico`
- [x] exe 内含 ≥3 个 `RT_ICON` 资源（实测 7 个）
- [x] 真实 exe：窗口 `WM_GETICON` 的 SMALL/BIG 均非 0
- [x] 桌面快捷方式指向新 exe（`update_shortcut.py` 自动重建）

## 已知边界

- Windows 会缓存图标（`IconCache.db`）。若更新后资源管理器仍显示旧图标，
  属系统缓存未刷新，可重启资源管理器或等待系统自行更新；
- ICO 内各档都由同一张母版缩放生成，未做小尺寸手工像素对齐
  （16px 的笔画有轻微抗锯齿，但不影响辨识）。
