# REQ-017 · 关闭结果提示自动消失

- **状态**：已完成（v1.16.0）
- **提出**：2026-10-26
- **目标版本**：v1.16.0
- **关联**：FEAT-003（关闭全部）、FEAT-017、T-021

## 背景

「关闭全部」完成后弹一个 `QMessageBox.information`（关闭结果 + OK 按钮），
每次都要用户点一下 OK 才能继续。用户要求：

> 在关闭完所有的程序后，不用让我点 OK 那个按键，只需要显示 5s 然后自己关掉
> 就行了，除非有软件关闭失败了，再让我点按钮什么的。

## 期望行为

1. **全部关闭成功**：结果提示显示约 5 秒后自己消失，全程不需要用户点任何按钮；
2. **有失败项**：保留原来的按钮确认框（失败需要人来处理——看日志、手动结束），
   自动消失会让这份信息被错过；
3. 提示期间主界面不被挡住（非模态，关完还能立刻继续操作启动器）；
4. 文案四种语言同步（中 / 英 / 日 / 繁）。

## 关键决策

| 决策 | 理由 |
|---|---|
| 自绘 `AutoCloseNotice`，不用 `QMessageBox + NoButton` | 实测 Qt 在 `exec_()` 阶段仍会给无按钮的消息框**自动补一个 OK 按钮**，达不到"不用点"；e2e 首轮就抓到了这个 OK |
| 非模态（`show()` 不是 `exec_()`） | 成功信息只需被看到；模态会挡住主界面 5 秒，没必要 |
| `Qt.Tool` + 置顶 + 无边框 | 不占任务栏、浮在其它窗口上保证可见、观感与设置面板的米白卡片（`CardFrame`）同族 |
| 点击提示可立即关闭 | 保留"想马上关就能关"的出口，但不点也能走完 |
| 失败分支维持 `QMessageBox.information` | 见期望行为第 2 条 |

## 验收标准

见 `06-测试/验收记录.md` T-021；核心断言：
提示无按钮、非模态（主界面 `isEnabled()` 保持 True）、~5 秒自关、
四语文案齐全且不回落；真实进程端到端（记事本）通过。
