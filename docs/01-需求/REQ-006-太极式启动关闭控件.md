# REQ-006 · 顶部太极式启动 / 关闭控件

- **状态**：待验收（目标版本 v1.8.0）
- **提出日期**：2026-10-20
- **关联**：FEAT-008、T-009

## 背景

原界面把「🚀 一键启动」与「⏹ 关闭全部」做成两个并排的普通按钮，夹在「添加程序／添加文件夹／录制宏」等按钮之间：

1. **不显眼**：两个最常用的动作淹没在一排按钮里；
2. **易误触**：启动与关闭语义相反，却只靠文字区分，外观几乎一样；
3. **不美观**：与其余工具按钮同质，缺少视觉重心。

## 期望行为

1. 在**窗口顶部**单独占据一块区域，水平居中，不与其它功能按钮混排。
2. 形态为一个**圆形控件**：左半圆绿色 = 一键启动，右半圆红色 = 关闭全部。
3. 整圆具备**3D 凸起质感**（对角渐变 + 顶部高光 + 底部内阴影 + 落影 + 外圈上亮下暗描边），不是纯色平面。
4. 点击行为严格按半圆划分：点左半只启动、点右半只关闭；点在圆外不响应。
5. 按下后把鼠标移出圆外再松开 → **不触发**（防误触）。
6. 悬停到某一半时该半有高亮反馈。
7. 启动进行中：左半置灰不可点，**右半仍可用**（可以边启动边关闭）。
8. 圆的大小"适中"：默认直径 132 px，窗口可整体缩放。

## 决策记录

| 日期 | 议题 | 结论 | 理由 |
|---|---|---|---|
| 2026-10-20 | 分割方式 | 垂直直径直切（左绿右红） | 按用户描述："左半边绿色一键启动、右半边红色一键关闭" |
| 2026-10-20 | 3D 实现方式 | 纯 `QPainter` 绘制，不引入图片资源 | 无额外资源、可任意缩放、配色可参数化调整 |
| 2026-10-20 | 文字方向 | 两个半圆都**自上而下** | 左侧若自下而上阅读，不符合中文阅读习惯 |
| 2026-10-20 | 位置 | 顶部单独一行、居中 | 用户要求"放在顶部显眼的地方，不要和其它功能堆在一起" |
| 2026-10-20 | 交互兜底 | 圆外不响应 + 拖出松开不触发 | 圆形控件的点击区比矩形更容易误触边缘 |

## 验收标准

- [x] 顶部出现独立圆形控件，居中，直径 132 px，与预设行分开
- [x] 左半绿、右半红，具 3D 凸起效果（渐变 + 高光 + 内阴影 + 落影 + 外圈）
- [x] 点左半发出启动、点右半发出关闭，圆外点击无响应
- [x] 左半禁用时点击无效，右半不受影响
- [x] 按下后移出圆外松开不触发
- [x] 悬停高亮、离开后复位
- [x] 启动中左半置灰，启动结束后自动恢复
- [x] 原有「一键启动」「关闭全部」的功能与确认流程不变

## 后续可微调项（等用户反馈）

- 直径（132 → 更小/更大）、是否加外圈刻度/文字标签
- 配色深浅、是否改成真正的 S 形太极分割线
- 是否在圆下方补一行说明文字（"启动 / 关闭"）
