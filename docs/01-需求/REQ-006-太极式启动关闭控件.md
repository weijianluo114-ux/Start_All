# REQ-006 · 顶部太极式启动 / 关闭控件

- **状态**：待验收（目标版本 v1.8.0）
- **提出日期**：2026-10-20
- **关联**：FEAT-008、T-009

## 背景

原界面把「🚀 一键启动」与「⏹ 关闭全部」做成两个并排的普通按钮，夹在「添加程序／添加文件夹／录制宏」等按钮之间：

1. **不显眼**：两个最常用的动作淹没在一排按钮里；
2. **易误触**：启动与关闭语义相反，却只靠文字区分，外观几乎一样；
3. **不美观**：与其余工具按钮同质，缺少视觉重心。

## 期望行为

1. 在**窗口顶部**单独占据一块区域，水平居中，不与其它功能按钮混排。
2. 形态为**太极阴阳图**：S 形曲线分成两条鱼，左半绿 = 一键启动，右半红 = 关闭全部。
3. 两条鱼之间要有**缝隙**，看起来是两块独立实体，而不是一个圆被涂成两色。
4. 整体要有**凹凸感**（浮雕/压铸质感），不是平面色块。
5. 文字**竖排**：每个字正立、自上而下排列（不是把横排文字旋转 90°）。
6. 点击行为严格按鱼身划分：点绿鱼只启动、点红鱼只关闭；点在缝隙或圆外不响应。
7. 按下后把鼠标移出鱼身再松开 → **不触发**（防误触）。
8. 悬停到某条鱼时该鱼有高亮反馈。
9. 启动进行中：绿鱼置灰不可点，**红鱼仍可用**（可以边启动边关闭）。

## 决策记录

| 日期 | 议题 | 结论 | 理由 |
|---|---|---|---|
| 2026-10-20 | 分割方式 | 初版为垂直直切；**第二版改为 S 形太极分割** | 用户明确要求"要太极阴阳图" |
| 2026-10-20 | 缝隙 | 用 `QPainterPathStroker` 从鱼形中真实减掉 5 px | 用户要求"按钮要有缝隙"，描边模拟缝隙会露馅 |
| 2026-10-20 | 凹凸感 | 沿轮廓用对角渐变画笔描边（浮雕） | 纯渐变只是明暗，压铸质感需要"边缘有高光也有暗边" |
| 2026-10-20 | 文字 | 逐字竖排，落在各自鱼身上 | 用户要求"文字竖着且竖着排布"；旋转 90° 会被读成横排 |
| 2026-10-20 | 鱼眼 | 左鱼嵌红点、右鱼嵌绿点 | 太极图符号必需，同时强化两块的对立关系 |
| 2026-10-20 | 配色 | 玉绿 + 朱砂红，压低明度与饱和差 | 用户反馈"配色怪怪的"——首个版本偏糖果色 |
| 2026-10-20 | 位置 | 顶部单独一行、居中 | 用户要求"显眼、不和其它功能堆一起" |

## 验收标准

- [x] 顶部出现独立圆盘，居中，直径 160 px，与预设行分开
- [x] S 形分割：上段小圆右半 + 下段小圆左半，两条鱼形态正确
- [x] 两条鱼之间有可见缝隙，缝隙处点击不响应
- [x] 具备浮雕式凹凸感（边缘上亮下暗 + 顶部高光 + 底部内阴影 + 落影 + 外圈包边）
- [x] 鱼眼：左鱼红点、右鱼绿点
- [x] 文字竖排，且不压到缝隙
- [x] 点绿鱼发出启动、点红鱼发出关闭，圆外与缝隙无响应
- [x] 绿鱼禁用时点击无效，红鱼不受影响；禁用态文字改为深灰以保证可读
- [x] 按下后移出再松开不触发；悬停高亮、离开复位
- [x] 原有「一键启动」「关闭全部」的功能与确认流程不变

## 后续可微调项（等用户反馈）

- 直径（160 偏大还是偏小）、缝隙宽度（当前 5 px）
- 配色深浅（当前绿 `#2B815C`、红 `#AB4132`）
- 是否需要更明显的"凸起"（可加大浮雕描边宽度）
- 是否在圆下方补一行说明文字
