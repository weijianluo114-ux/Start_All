# REQ-010 · 设置面板与开机自启动

- **状态**：已完成（v1.10.0）
- **提出**：2026-10-21
- **关联**：FEAT-010、REQ-008（设置入口）

## 背景

v1.9.0 起圆右侧下角有「设置」胶囊，但只是占位：点击弹一句"尚未实现"，不改任何配置。
本次要求给它接上真实功能，第一个选项为**开机自启动**，并明确三点视觉约束：

1. 设置界面要与现有界面（暖色面板 + 象牙白卡片 + 绿/红圆盘）风格统一；
2. 鼠标悬停的高亮要做好；
3. 设置窗口不需要大。

## 期望行为

1. 点「设置」打开独立面板，**改动即时生效**，没有「保存 / 取消」按钮；
2. 面板内提供「开机自启动」开关，开启后登录 Windows 时自动打开启动器；
3. 开关状态与系统真实状态一致：外部改动（手动删注册表项）再次打开面板要如实反映；
4. 写入失败时开关**回滚**并说明原因，不留下"看起来开了其实没开"的假象；
5. 窗口保持小尺寸（400×224），风格与主界面同源。

## 实现方式

| 项 | 做法 |
|---|---|
| 注册表位置 | `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` |
| 值名 | `LaunchForge`，类型 `REG_SZ` |
| 值内容 | frozen 时 `"<当前 exe 完整路径>"`；源码运行时 `"<pythonw.exe>" "<launchforge.py>"` |
| 权限 | 只需 HKCU，**不触发 UAC**；程序本身是绿色单文件，提权得不偿失 |
| 状态判定 | `autostart_state()` 返回 `(是否存在, 命令, 是否指向当前程序)`，不是"看键存不存在" |
| 升级自愈 | `heal_autostart_path()`：仅当记录的文件**确实不存在**时改写为当前程序 |
| 控件 | 新增 `ToggleSwitch`（52×28，纯 QPainter）、`SettingRow`（90 高卡片，整行可点） |
| 面板 | 新增 `SettingsDialog`（400×224），每次打开重读注册表，不持有状态 |

## 关键取舍

### 1. 为什么不用 `QCheckBox`

勾选框与暖色面板 + 象牙白胶囊的质感不搭，且 QSS 无法给 QCheckBox 画滑块、过渡与内阴影。
自绘开关的代价是约 150 行绘制代码，收益是配色与圆盘完全同源、放大 2 倍仍清晰。

### 2. 为什么必须有"升级自愈"

本项目产物名带版本号（`LaunchForge_vX.Y.Z.exe`），且约定"仓库根只保留当前版本"，
升级后旧 exe 会被 `clean_artifacts.py` 删除。若不处理，注册表里那条命令会指向不存在的文件，
**开机自启动会静默失效**，而用户完全看不出来。

自愈只在"指向的文件确实不存在"时触发；指向另一份仍存在的副本时不动，
避免抢占用户自己保留的另一份安装。

### 3. 为什么整行可点

52×28 的开关在 400px 宽的窗口里偏小，要求精确瞄准不合理。
整行（360×90）都可点击，命中面积扩大约 8 倍；开关本身也保留独立的点击区域。

### 4. 为什么没有「应用」按钮

一个开关没有批量确认的必要。即时生效 + 失败回滚 + 状态回读，比"改完再保存"更不容易出错。

## 验收标准

- [x] 开启后注册表可读回与 `autostart_command()` 完全一致的命令
- [x] 重复开启 / 重复关闭均幂等，不报错
- [x] 指向不存在的文件时 `same=False`；指向仍存在的文件时不做自愈
- [x] 面板构造即反映注册表状态；点整行与点开关都能写入
- [x] 写失败时开关回滚且弹出原因
- [x] 悬停时边框、底色、状态竖条三处像素均发生变化
- [x] 窗口 400×224，内容不溢出
- [x] 测试全程使用独立注册表沙箱键，真实 Run 键零改动
- [x] T-001～T-004、T-008～T-011 全部回归通过

## 决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-21 | 用 HKCU 而不是 HKLM | HKLM 需要管理员权限，会弹 UAC；单文件工具的定位不允许 |
| 2026-10-21 | 值名固定为 `LaunchForge`，不带版本号 | 值名带版本号会在每次升级后残留多条，越积越乱 |
| 2026-10-21 | 自愈只在"目标文件不存在"时触发 | 无条件改写会抢占用户另一份存在的副本 |
| 2026-10-21 | 窗口 400×224，只放一个开关 | 用户要求"不需要太大"；宁可后续按需加页，也不先摆一排不生效的项 |
| 2026-10-21 | 提示行只显示程序名，完整命令放 tooltip | 400px 宽塞不下完整路径；显示半截更难看 |
