# REQ-008 · 圆侧胶囊操作区

- **状态**：已完成（v1.9.0）
- **提出**：2026-10-20
- **关联**：FEAT-009、REQ-006

## 背景

v1.8.0 把启动 / 关闭做成顶部一颗太极圆盘，但其余六项操作还堆在圆盘下方两行按钮里：
圆盘被按钮包围，主视觉被稀释；而「录制总宏」等按钮与启动流程混排在同一视线里。

## 期望行为

1. 六项操作（添加程序、添加文件夹、输入路径、删除选中、日志、设置）分列**圆盘左右两侧**，各 3 项；
2. 「设置」只留入口（**v1.10.0 已接上设置面板**，见 REQ-010）；
3. 胶囊条呈圆角矩形，**长度按字数不同**：字数多的更长；
4. 位置规则：**长条靠圆的上下两端，短条靠近中间**（与圆心齐平）；
5. 配色方向：象牙白 + 灰金（浅底、暖灰金描边、深灰字）；
6. 圆盘本身：绿更浅、红更接近鲜血。

## 实现方式

| 项 | 做法 |
|---|---|
| 控件 | `PillButton`（宽度由 `fontMetrics.horizontalAdvance` + 左右内边距算出，高度固定 38，圆角取 19） |
| 分列 | `PillColumn(buttons, align, height)`：绝对定位，三枚中心距 `CENTER_GAP=66`，中间那枚与容器中心重合 |
| 对齐 | 左列右对齐（右缘贴圆）、右列左对齐（左缘贴圆） |
| 尺寸 | 圆直径 160（控件 192）；窗口 560×700 |
| 层次 | 暖白面板 `#EDE7DB` → 象牙白胶囊（`#FFFFFF → #F1E9D9` 竖向渐变）→ 纯白列表，三层明度 |
| 预设行 | 「新建 / 删除」改用 `PillButton(compact=True)`，与侧栏同源，避免风格割裂 |

左右分配与顺序：

| 位置 | 左列 | 右列 |
|---|---|---|
| 上（最长） | 添加文件夹（5 字） | 删除选中（4 字） |
| 中（与圆心齐平） | 添加程序（4 字） | 日志（2 字） |
| 下 | 输入路径（4 字） | 设置（2 字） |

> 左列两个 4 字条等长，按"最常用优先"把「添加程序」放在中间。

## 验收标准

- [x] 六枚胶囊宽度随字数递增（2 字 86px < 4 字 96px < 5 字 111px）
- [x] 每列三枚中心 y 相对列中心为 −66 / 0 / +66，中间那枚与圆心同高
- [x] 左右列不压到圆，且与圆之间空隙 ≤ 24px
- [x] 「设置」点击只弹提示，配置文件字节未变
- [x] 宏入口全部消失（见 REQ-007）
- [x] T-001～T-004、T-009 全部回归通过

## 决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-20 | 胶囊文字去掉 emoji，改纯文字 | 彩色 emoji 与象牙白 + 灰金冲突；`▤`、`⌨` 等单色符号在雅黑下缺字，会显示成方块 |
| 2026-10-20 | 不使用 `QGraphicsDropShadowEffect` | 阴影会把整枚按钮先离屏渲染再模糊，中文会发虚；改用"上沿亮边 + 下沿暗边 + 竖向渐变"做压铸感 |
| 2026-10-20 | 用绝对定位而非 `QVBoxLayout` | 布局只能平均分配剩余空间，做不到"中间那枚严格与圆心齐平" |
