# REQ-012 · 全局字体设置

- **状态**：已完成（v1.12.0）
- **提出**：2026-10-21
- **目标版本**：v1.12.0
- **关联**：FEAT-012、REQ-011（字体层级）、REQ-010（设置面板）

## 背景

v1.11.0 把字体层级做细了，但**家族与字号都写死在代码里**：

- 用户不喜欢「思源标题 + 雅黑正文」这套观感时，只能改源码重新打包；
- 13px 正文在 2K/4K 屏或视力不佳的用户看来偏小，在 1080p 高分屏上又偏大；
- 设置面板里已经有「开机自启动」，字体这类**纯偏好**却没有入口，二者体验不一致。

要求：在设置里给出字体搭配选择（附 3–5 套推荐）与全局字号滑块，且**两端极值下界面
不能出现重叠、越界、文字被裁**。

## 期望行为

1. 设置面板新增「字体搭配」下拉，列出 3–5 套推荐搭配，选中即生效，无需重启；
2. 新增「字号」滑块，范围为界面正文 11–17px，拖动过程中实时预览，松手落盘；
3. 选择结果写入配置文件，下次启动按保存值渲染；
4. 本机缺字体时沿候选链回退，不报错、不出现方块；
5. **11px 与 17px 两端**：预设行、胶囊、圆盘、列表、设置面板均不重叠、不越界，文字不被裁；
6. 主窗口布局结构不变（太极圆 + 两侧胶囊 + 列表），只随字号自适应。

## 不在本次范围

- 不做「逐控件自定义字体」（层级固定为 标题/正文/说明三档，避免界面失控）；
- 不引入字体文件安装（只用本机已安装字体，缺失即回退）；
- 不做字体颜色的主题切换（配色仍走 `Theme` 令牌）；
- 不改变程序列表行内文字的省略策略（仍是中间省略）。

## 验收标准

- [x] 推荐搭配 3–5 套、key 唯一、每套可选且解析到本机存在的家族
- [x] 非法配置（未知 key / 越界字号）收敛到合法值，程序照常启动
- [x] 基准档（13px）与 v1.11.0 的像素结果完全一致（老用户观感不变）
- [x] 11px / 17px 下：三条横带不重叠、两侧胶囊不压圆盘、文字宽度不超过胶囊内宽
- [x] 11px / 17px 下：设置面板内所有控件落在面板内，卡片内控件不越界
- [x] 滑块点击两端、键盘 Home/→/End 都落到正确档位；拖动只预览、松手才写盘
- [x] 面板改字号后主窗口字体与胶囊宽度同步变化，且配置已落盘
- [x] T-001～T-013 全部重跑通过

## 实现要点

| 项 | 做法 |
|---|---|
| 偏好状态 | 模块级 `FontPrefs`（`KEY` / `SIZE`）+ `FONT_PRESETS` 五套搭配 |
| 字号换算 | `ui_font(size)` 里的 `size` 是**基准字号**，实际像素 = `round(size × SIZE/13)`，下限 10px |
| 字族回退 | `_resolve_families()` 返回已安装家族列表，交给 `QFont.setFamilies()` 逐字回退 |
| 即时生效 | `set_ui_font()` 把基准 spec 记录在控件上，`restyle_widgets()` 遍历控件树重建 |
| 不重建窗口 | 重建会丢 `launched_items`（文件类条目的 PID），改字号后关不掉刚打开的文件 |
| 高度自适应 | `SettingRow.sync_height()`、`ListRowDelegate.row_height()`、`SettingsDialog._fit_height()` 都按字体实算 |
| 落盘 | `settings.font_key` / `settings.font_size`，与 `last_folder` 同处一个 JSON |

## 决策记录

| 日期 | 议题 | 结论 | 理由 |
|---|---|---|---|
| 2026-10-21 | 字号用 px 还是百分比 | 直接用 11–17px | 用户能对上自己屏幕上的真实字号，百分比还要心算基准 |
| 2026-10-21 | 改字号后是否重建窗口 | 不重建，按 spec 重建字体 | 重建会丢 `launched_items`，关不掉改字号前打开的文件 |
| 2026-10-21 | 滑块拖动是否逐档写盘 | 拖动只预览，松手才写 | 一次拖动经过 6 档，写 6 次配置既慢又可能写坏 |
| 2026-10-21 | 圆盘文字是否等比跟随 | 只跟随 0.94–1.16 倍 | 圆盘是插画，字再大就压到 S 形缝隙和盘沿 |
| 2026-10-21 | 默认搭配 | 「雅黑 × 思源」= 与 v1.11.0 相同 | 升级不能改变老用户已经看惯的观感 |
