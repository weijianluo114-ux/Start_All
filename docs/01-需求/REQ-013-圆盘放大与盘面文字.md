# REQ-013 · 圆盘放大与盘面文字修正

- **状态**：已完成（v1.13.0）
- **提出**：2026-10-21
- **目标版本**：v1.13.0
- **关联**：FEAT-013、REQ-006（太极控件）、REQ-011（字体）、REQ-012（全局字体）

## 背景

v1.11.0 给圆盘加了"字号跟随"（0.94–1.16 倍），结果 17px 全局字号下「启动 / 关闭」
四个字**跨过了中间的 S 形缝隙**：第二字压到了另一条鱼身上，红字压在绿鱼里、绿字压进红鱼里。

原因是文字框按"圆心偏移 + 固定宽度"摆放，而 S 形边界在 `y = cy` 处会从 `cx + 0.5R`
突然跳到 `cx - 0.5R`，任何跨过中线的固定框都必然越界。

另外两点观感问题：

1. 圆盘 160 偏小，字贴在盘沿上；
2. 白字压在玉绿 / 朱砂上显得生硬，和暖金面板没有呼应；悬停时只有底色变化，字本身不响应。

## 期望行为

1. 圆盘整体放大（160 → 184），字既不贴盘沿也不压缝；
2. 盘面字体换成更可爱的**圆体**（幼圆），不用纯白；
3. 悬停时**字本身**高亮：字芯变亮 + 出现柔光，且只亮被悬停的那一半；
4. 11px / 13px / 17px 全局字号下都不越界（字号自适应）；
5. 圆盘是插画：不跟随「设置 → 字体搭配」变成宋体/衬线。

## 不在本次范围

- 不做逐字旋转（沿弧线排版），保持竖排两字；
- 不改太极的 S 形几何与缝隙宽度；
- 不引入字体文件（只用本机圆体，缺了就退 MiSans → 界面字体）。

## 验收标准

- [x] `TaijiLaunchButton.DIAMETER == 184`，控件 216×216（含落影边距）
- [x] 本机有圆体时盘面字体为幼圆；切到「书卷衬线」盘面不变
- [x] 三档全局字号下，每个字盒的 5×5 采样点都在本侧鱼身内
- [x] 每个字盒四角离盘沿 ≥4px，且不与鱼眼相交
- [x] 两字共用同一竖列（不左右错开）
- [x] 字芯为暖金 `#FFD79A`，非纯白；深可可描边 `#5B2C00` 1.25px
- [x] 悬停时字区像素变化 > 120，未悬停侧 >90% 像素不变
- [x] 禁用态文字转灰 `#6F6F6F`
- [x] 布局按 (直径, 字号倍率, 字族) 缓存，改字号自动失效

## 实现要点

| 项 | 做法 |
|---|---|
| 轮廓感知 | `_fish_span(side, y0, y1)`：对区间内 9 条扫描线求"鱼身可用区间"的交集 |
| 字块位置 | 左鱼整块在 `cy - 0.06R` 以上、右鱼在以下；两字共用区间中线 |
| 自适应字号 | 从目标字号逐档缩，直到四角都在鱼身内且离盘沿 ≥5px（`_text_layout` 缓存） |
| 鱼眼避让 | 左鱼把可用区间右界压到 `cx - eye_r - 4`，右鱼反之 |
| 字体 | `TAIJI_FONTS = ('幼圆','YouYuan','MiSans')` → 界面字体兜底 |
| 配色 | 暖金字芯（竖向渐变）+ 深可可 8 向描边；悬停时字芯变亮、描边转暖、外圈柔光 |
| 性能 | 布局与字体只在 (直径, 倍率, 字族) 变化时重算，悬停帧只改画笔颜色 |

## 决策记录

| 日期 | 议题 | 结论 | 理由 |
|---|---|---|---|
| 2026-10-21 | 怎么保证不跨缝 | 按实际轮廓算可用区间，不再用固定框 | S 边界在中线处突变，任何固定框都会越界 |
| 2026-10-21 | 圆盘多大 | 184（+15%） | 再大字会挤薄盘沿，再小 17px 字号又显得局促 |
| 2026-10-21 | 字色 | 暖金 + 可可描边，不用白 | 白字在这两种底色上都生硬；金色与 UI 的金线同源 |
| 2026-10-21 | 盘面字体是否跟随设置 | 不跟随，固定圆体 | 圆盘是插画，用户选衬线是给正文的，不代表要让按钮变宋体 |
| 2026-10-21 | 字号是否跟随全局 | 只 ±8%，且受盘沿约束 | 盘面是固定几何，字跟着界面放大必然贴边 |
