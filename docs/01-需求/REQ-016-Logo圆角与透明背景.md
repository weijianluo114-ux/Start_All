# REQ-016 · Logo 圆角与透明背景

- **状态**：已完成（v1.16.0）
- **提出**：2026-10-21
- **目标版本**：v1.16.0
- **关联**：FEAT-015（前身：方块黑框版）、FEAT-016、T-020

## 背景

v1.15.0 定稿的 logo 是「方块黑框 + 满幅米白底」，放进深色 / 彩色界面时
会带着一整块米白方底，与任何背景都格格不入。用户要求：

> 将现有的黑色矩形边框改为圆角边框，并去除边框以外的白色背景部分，
> 使背景变为透明。请保持内容、尺寸和整体布局不变，确保圆角过渡自然，
> 输出结果可直接使用。

本条同时修订 REQ-015 的第 5 点（「不加外部圆角」）——那是当时
"图标交给 Windows 处理"的取舍，现在用户明确要求圆角 + 透明，以新为准。

## 期望行为

1. 黑框四角改圆角，过渡自然（有抗锯齿，不得出现阶梯状锯齿）；
2. 黑框**以外**的米白背景全部透明（alpha=0）；
3. 黑框**以内**的内容与米白底原样保留（S、A、波浪线、内部留白）；
4. 箭头穿出黑框的那一截保留——透明化不是"裁到框内"，否则箭头被截断；
5. 尺寸不变（780×780），黑框位置与 v1.15.0 一致（±4px）；
6. 圆角边缘不得残留白边 / 米白雾（深色背景上看得最清楚）；
7. 七档 ICO 同步重新生成，exe / 窗口 / 任务栏 / 快捷方式三条路径同源；
8. 生成过程脚本化（`scripts/make_logo.py`），从 `assets/logo_src.png`
   一条命令可复现，避免"脚本和成品脱节"。

## 关键决策

| 决策 | 理由 |
|---|---|
| 圆角半径 72px（占外框宽 11%） | 40/56/72/88 四档出图对比：56 与直角差别不大，88 的弧压到内框手绘抖动处，72 最自然 |
| 框内米白底**不透明保留** | 用户要求"仅保留黑框内部区域的内容与背景"；清掉会露出任意背景，S/A 的可读性崩掉 |
| 箭头打断边框处的米白一并保留（补实） | 那是原画"箭头顶开黑框"的留白，属于框内区域；清掉则箭头像浮在背景上 |
| 边缘颜色用「反解前景色」而非「最近实心色」 | 源图边缘是 `前景×米白` 混色；按 alpha 反解 `fg=(obs-(1-a)·bg)/a` 在米白底上与源图逐像素相等，换背景无色偏；反解过冲的离群像素再吸附到最近实心色 |
| 不能用连通性补洞 | 箭头把黑框打断，框内米白与画布外的米白实测连通，任何"被围住的透明区"判定都会漏 |

## 验收标准

见 `06-测试/验收记录.md` T-020；核心断言：
四角与外圈 3px 全透明、黑框位置 ±4px、半透明像素颜色全部贴近黑/黄实心色、
ICO 七档轮廓外零浅色残留、`make_logo.py --dry-run` 与成品逐像素一致。
