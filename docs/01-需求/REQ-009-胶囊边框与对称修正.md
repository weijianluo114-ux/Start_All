# REQ-009 · 胶囊的边框、对齐与内外圆角修正

- **状态**：已完成（v1.9.0，随 REQ-008 一并发布）
- **提出**：2026-10-20
- **关联**：FEAT-009、REQ-008

## 背景

REQ-008 的第一版胶囊有四处视觉问题：

1. 每枚胶囊的上沿被单独设成浅白（`border-top-color`），在浅色面板上看起来是"一条白边"，与其余三边不一致；
2. 三枚胶囊宽度不同却**右对齐**，左边缘参差，左列没有一条共同基准线；
3. 同一排左右两枚长度不同（如左 111 / 右 96），上下两排也不等长，整体不对称；
4. 四角都是全圆角，缺少"朝内贴圆、朝外收平"的层次。

## 期望行为

1. 去掉上沿白色描边，**四周边框同色**；
2. 左列三枚**左边缘对齐**（取更靠面板左侧的那条线），右列三枚**右边缘对齐**；
3. 同一排左右等长，且上排与下排等长 —— 左右成对、上下镜像；
4. 左侧胶囊**左边小圆角、右边大圆角**；右侧胶囊**右边小圆角、左边大圆角**，形成内外呼应。

## 实现方式

| 项 | 做法 |
|---|---|
| 边框 | 只留 `border: 1px solid #BEAD86`，删除 `border-top-color` / `border-bottom-color` 覆写（含 hover / pressed 态） |
| 四角 | 改用 `border-top-left-radius` 等四个独立属性；`PillButton._apply_style()` 按 `small_side` 生成 |
| 小圆角 | `SMALL_RADIUS = 8`；大圆角仍是高度一半（19） |
| 宽度 | `LauncherWindow` 先算两档宽度 `w_outer`（上/下排）、`w_mid`（中排），左右两列共用同一组 `row_widths` |
| 对齐 | `PillColumn(side='left')` → `x = 0`；`side='right'` → `x = 列宽 − 按钮宽` |

宽度取值（v1.9.0 实测）：

| 排 | 左列 | 右列 | 统一宽度 |
|---|---|---|---|
| 上 | 添加文件夹 | 删除选中 | **111** |
| 中 | 添加程序 | 日志 | **96** |
| 下 | 输入路径 | 设置 | **111** |

> 上排与下排同值，保证关于中线镜像；中排独立但左右等长。
> 长度差异仍在（111 / 96），没有退化成六条等宽。

## 验收标准

- [x] 胶囊样式表内不存在 `border-top-color` / `border-bottom-color`
- [x] 左列三枚 `x == 0`；右列三枚 `x + width == 列宽`
- [x] 左右两列等宽（111 = 111）；同一排左右等长；上排 == 下排
- [x] 左列 `border-top-left-radius: 8px` + 右侧 19px；右列反之
- [x] 圆心 y == 两列中心 y（偏差 ≤ 1px）
- [x] 左右留白对称（61 / 62，1px 为 `QRect.right()` 的边界差）
- [x] T-001～T-004、T-008 全部回归通过

## 决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-20 | 小圆角取 8px（高度 38） | 比 19px 明显更方，但又不是直角；放大 5 倍看仍保留一点弧度 |
| 2026-10-20 | 宽度只保留两档，不做六条等宽 | 用户要"长度对称一致 + 上下对称"，成对等宽已满足；全等宽会让上一版"按字数定长"的设计完全消失 |
| 2026-10-20 | 边框四边同色，取消上下沿明暗 | 压铸感改由背景渐变单独承担；白上沿在浅色面板上过于抢眼 |
