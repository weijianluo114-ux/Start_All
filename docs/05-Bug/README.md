# 05-Bug

缺陷追踪。一个 Bug 一条记录，**不删不改号**，修复后保留全过程，便于日后回归。

## 生命周期

`新建` → `已确认` → `修复中` → `待回归` → `已关闭`
分支状态：`不予修复`（写明理由）、`无法复现`（写明尝试过的环境）

## 严重度

| 级别 | 含义 |
|---|---|
| 致命 | 程序无法启动 / 数据丢失 |
| 严重 | 主要功能不可用，无绕过办法 |
| 一般 | 功能异常但有绕过办法 |
| 轻微 | 文案、布局、体验问题 |

## 记录要求

- **现象只写看到的**，原因放「根因」段落，避免"现象"里混入猜测。
- 必须写可复现步骤；偶发问题注明复现率。
- 修复后必须写回归验证，说明是否补了自动化测试。
