## T-001 · 取消打开即启动

**做法**：造一份 `auto_launch: true` 的旧配置，预设里放一个"被执行就写标记文件"的探针 `.bat`；
创建主窗口后让事件循环空转 3.5 秒（旧版 300 ms 就会触发），检查标记文件。

```
python test_step1_no_autolaunch.py
```

输出：

```
[1] 窗口已创建，列表条目数 = 1
[2] 空转 3.5s 后，探针标记存在 = False （应为 False，说明没有自动启动）
[3] 菜单栏 action 数 = 0 （应为 0，说明「设置」菜单已移除）
[4] 点击「一键启动」后，探针标记存在 = True （应为 True，说明手动启动正常）

需求 1 验收通过：打开只显示界面，点击按钮才启动。
```

**对照实验**（同一脚本，`LF_SRC=baseline` 切到改造前代码）：

```
[2] 空转 3.5s 后，探针标记存在 = True （应为 False，说明没有自动启动）
AssertionError: 打开即启动的行为仍然存在！
```

结论：测试确实能捕捉该行为，不是"空跑通过"。

## 回归约定

改动 `close_all_programs` / 启动流程后，至少重跑 T-001、T-002 两个脚本；
若涉及配置文件结构，另需手工验证"旧配置能被正确载入"。
改动列表条目类型（程序 / 文件 / 文件夹）相关逻辑时，追加 T-003。
改动关闭策略（PID / 镜像名 / 提权）时，追加 T-004。
改动任何 `subprocess` 调用时，追加 T-007（否则可能引入控制台黑框）。
改动文件夹打开方式时，追加 T-003（脚本级）与产物端到端验证（T-006）。
改动 `close_all_programs` 的判定范围（新增/减少关闭对象类型）时，追加 T-008；
改动资源管理器窗口的枚举或关闭方式（`list_explorer_windows` / `_close_folder_window`）时，
必须重跑 T-008 的**多标签专项**——单标签能过关不代表多标签能过关。
改动顶部太极控件（`TaijiLaunchButton`）的命中判定、信号接线或启用状态时，追加 T-009。
改动圆侧胶囊的宽度算法（`PillButton.sizeHint`）或列内定位（`PillColumn`）时，追加 T-010。
改动启动方式（`launch_program` / `open_via_shell`）或关闭时的目标判定（`_close_targets` /
`find_pids_by_commandline` / `assoc_executable`）时，追加 T-011——文档类条目最容易在这里回归。
改动注册表写入（`set_autostart` / `heal_autostart_path`）或设置面板控件时，追加 T-012。
改动字体令牌（`Theme` / `ui_font`）、胶囊绘制或列表 delegate 时，追加 T-013；
改动字体偏好（`FontPrefs` / `FONT_PRESETS` / `set_ui_font` 的 spec 机制）或设置面板布局时，
追加 T-014——**两端极值（11px / 17px）都要跑**，中间档通过不代表两端不越界。
改动圆盘直径、盘面字体或 `_fish_span` / `_text_layout` 的排布算法时，追加 T-015；
改动任何界面文案、`lf_i18n.py` 的译文表、`Lang` / `t()` 的回落逻辑，或设置面板的语言行时，
追加 T-016——**四种语言 × 两端字号都要跑**，中文通过不代表英文不越界（英文文案平均长 30%）。
**三档全局字号都要跑**（盘面字号是自适应的，只测 13px 会漏掉越界）。
**改动胶囊的点击区域与几何时，必须同时重跑 T-010**，两者共用 `PillColumn` 的定位规则。
**任何新写的注册表测试都必须指向沙箱键**，否则测试值会在下次登录时真正被执行。
改动任何自绘控件的焦点绘制（`focusInEvent` / `_keyboard_focused` / `_KB_FOCUS_REASONS`）时，
追加 T-017——**鼠标焦点必须与无焦点逐像素一致**，只要还差 1 像素就说明环还在画。
改动品牌资源（`assets/logo.ico` / `logo.png`）或打包参数里的 `--icon` 时，追加 T-019——
**必须同时核对 exe 里的 `RT_ICON` 数量**，只看界面换图会漏掉"exe 没换"。
改动 `.bat/.cmd` 的启动或伴生进程记录（`process_snapshot` / `descendants_of` /
`_spawned_processes` / `_spawn_still_same`）时，追加 T-018——**必须启动一个无关程序做对照**，
只验证"脚本的子进程能被关掉"是测不出误杀的（BUG-007 就是差集恰好也能关掉真子进程）。
从 `src/legacy/` 恢复任何功能时，先确认 `requirements.txt` 与打包依赖同步，再跑全量回归。
