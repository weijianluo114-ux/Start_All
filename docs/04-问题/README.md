# 04-问题

这里记录**不是缺陷**的东西：

- 设计上的疑问与待确认项（写需求时没想清楚的点）
- 技术方案的取舍（为什么选 A 不选 B）
- 环境限制、平台差异造成的"暂时无解"
- 用户可能遇到的困惑（可演化为 FAQ）

**缺陷请放 `05-Bug`**。判别标准：

| 类型 | 判据 |
|---|---|
| Bug | 代码没按已定需求工作，有明确的"应该"与"实际" |
| 问题 | 需求本身还没定，或存在无法消除的限制，需要决策 |
